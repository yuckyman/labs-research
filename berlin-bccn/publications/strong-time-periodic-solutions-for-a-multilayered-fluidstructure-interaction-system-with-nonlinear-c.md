# Strong time-periodic solutions for a multilayered fluid–structure interaction system with nonlinear coupling

## Abstract

                    We investigate a time-periodic fully three-dimensional fluid–structure interaction (FSI) system in which the Navier–Stokes equations for an incompressible viscous fluid are coupled with a multilayered elastic structure composed of a damped thin linear plate and a thick viscoelastic layer.
